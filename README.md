# Request System

사내 요청을 등록하고 관리하기 위한 Spring Boot 기반 웹 프로젝트입니다.

## 기술 스택

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Mustache
- Gradle

## 구현 기능

### Day01
- 요청 등록 기능
- MySQL DB 저장
- RequestForm DTO 구성
- Request Entity 구성
- RequestRepository 구성
- 요청 등록 화면 구현

## 개발 예정

- 요청 목록 조회
- 요청 상세 조회
- 요청 수정 및 삭제
- 요청 상태 관리
- 담당자 관리
- 검색 및 페이징
- 회원 및 권한 관리
- REST API
- 테스트 코드
